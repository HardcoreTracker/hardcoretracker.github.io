# Hardcore Point Tracker

Standings, punishments and death log for our shared-life hardcore server.

- `data.json` holds every player's starting points, nickname and skin, plus the death log.
- `skins/` holds each player's skin PNG.

Points per death: Wood–Stone +1, Copper +2, Iron–Explore +3, Diamond–Nether +4, End–Post End +5, +1 if a totem farm had been built. Every 5 points is a punishment.
